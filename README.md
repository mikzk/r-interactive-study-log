A learning log of R programming basics based on university coursework. Includes interactive study records with an AI assistant, covering data structures, numerical computing, and data frame operations.
# R Programming Interactive Study Log

大学の授業で配布された教材をもとに、R言語の基礎からデータ集計までを体系的に学んだ学習記録です。
単に正解のコードを書くだけでなく、AIアシスタントとの対話を通じて「予想 → 実行 → 解説」のサイクルを回しながら理解を深めました。
GeminiCILを用いたアクティブラーニングを行っています。

## 学習内容
以下のテーマについて、実際にコードを記述し、実行結果とエラーハンドリングの軌跡を記録しています。

* **Rの基礎**: 四則演算、数学関数、変数と代入 (`01_basics`)
* **データ構造**: ベクトル、行列、リストの概念と要素へのアクセス (`03_vectors_matrices_lists`)
* **制御構文**: 関数(function)の自作、条件分岐(if)、繰り返し(for) (`04_functions_programming`)
* **数値計算**: Rを用いた数値積分と関数の最適化（最小値探索） (`05_numerical_computing`)
* **データフレームとI/O**: データの作成、条件抽出、並べ替え、CSVファイルの入出力と集計 (`06_dataframes_io`)

## 学習アプローチ
* 提供された課題に対し、まずは実行結果を**予想**してからコードを記述。
* AIアシスタントからのフィードバック（エラー時の原因特定や、`str()`、`summary()`などの関数の深い解説）を受けながらコードを修正・完成させるスタイルで進行。
* 各章ごとに実践的なミニテストや演習問題をクリアしています。
